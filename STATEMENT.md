## Python Calculator

### Introduction

This project is a calculator program made using Python. The main idea was to make one program that can perform different mathematical operations by taking input from the user.
The program runs in the terminal and gives the user a list of operations to choose from. After completing one calculation, the user can either perform another calculation or exit the program.

### Operations Included

The calculator can perform the following operations:

1. Addition
2. Subtraction
3. Multiplication
4. Division
5. Power
6. Modulus
7. Factorial
8. Percentage
9. GCD and LCM
10. Average
11. Data conversion between Decimal, Binary, Octal and Hexadecimal

For division and modulus, the program also checks if the divisor is zero and displays an error instead of performing the calculation.

### How It Works

The program is divided into different functions. Each function is responsible for one operation. When the user selects an option from the menu, the corresponding function is called and takes the required values as input.
For data conversion, the user first selects the number system of the given value and then selects the number system in which the result is required.
The program uses basic Python concepts such as functions, `if-elif-else`, loops, user input, lists and some built-in functions.

### Objective

The objective of this project was to practise the basic concepts of Python by making something that can be used for simple calculations. It also helped in understanding how different functions can be combined into one menu-driven program.

### Conclusion

This project was made as a beginner-level Python project. While working on it, I got more practice with taking input, using conditions, creating functions and handling different types of calculations. It also helped me understand how a larger program can be divided into smaller parts to make it easier to manage.
