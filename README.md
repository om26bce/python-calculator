# Python Calculator

## About the Project

This is a simple calculator made using Python.

The main purpose of this project is to perform basic mathematical calculations through a Python program. It is a beginner-level project that helped me understand the basics of Python and how to use them to make a useful program.

The calculator runs in the terminal, so there is no need for a graphical interface.

## What This Project Can Do

The calculator is designed to perform basic arithmetic operations.

### 1. Addition

Adds two numbers and displays their sum.

### 2. Subtraction

Subtracts the second number from the first number.

### 3. Multiplication

Multiplies two numbers and displays the result.

### 4. Division

Divides the first number by the second number.

## Technologies Used

* Python 3
* Command Line / Terminal

## Requirements

To run this project, you need:

* Python 3 installed on your computer
* Any code editor, such as VS Code
* A terminal to run the program

No extra libraries are required for basic calculator operations.

## Project Type

* **Language:** Python
* **Interface:** Command Line / Terminal
* **Project Level:** Beginner

## Conclusion

This project helped me practise the basics of Python by creating a simple calculator. While making it, I got to work with basic operations, user input and other fundamental concepts of programming.

It was a good way to get started with Python and understand how a simple program works.

## Output

The program takes input from the user, performs the selected calculation and displays the result in the terminal.
